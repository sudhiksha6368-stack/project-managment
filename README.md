Project Management Tool

About the Project

The Project Management Tool is a web application designed to help users organize and track their tasks efficiently.

Features

- Add new tasks with descriptions and deadlines
- Edit existing tasks
- Delete tasks
- Set task priorities
- Track task status
- Search tasks
- View task summary counts
- Save tasks using browser local storage

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Start adding and managing your tasks.

Project Purpose

This project was developed as part of a Full Stack Development learning experience.
